# Module 2: Data Structures & File Handling

In Module 2, you'll transition from basic variables to working with structured data collections and storing data permanently in files.

## 📋 Topic Breakdown & Code Lessons
1. **`01_lists_and_tuples.py`** — Ordered collections, indexing, slicing, and list comprehensions.
2. **`02_dictionaries.py`** — Key-value pairs, nested data structures, and lookup operations.
3. **`03_file_handling.py`** — Reading/writing `.txt` files and parsing `.json` data.
4. **`04_error_handling.py`** — Preventing app crashes using `try`, `except`, and `finally`.

## 🎯 Module Project
Once you complete files `01` through `04`, run **`project_expense_tracker.py`** to build a command-line expense tracker that persists spending data to `expenses.json`!
