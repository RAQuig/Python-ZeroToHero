# Module 1: Python Essentials

Welcome to Module 1! Here you'll learn the core building blocks of programming.

## 📋 Topic Breakdown & Code Lessons
1. **`01_variables_and_types.py`** — Storing text, numbers, and booleans.
2. **`02_conditionals.py`** — Making decisions with `if`, `elif`, and `else`.
3. **`03_loops.py`** — Repeating actions using `for` and `while` loops.
4. **`04_functions.py`** — Packaging reusable blocks of code.

## 🎯 Module Project
Once you finish files `01` through `04`, open **`project_text_adventure.py`** and build your first full interactive text game!
