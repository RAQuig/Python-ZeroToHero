# 🐍 Python Zero to Hero Course

Welcome to our group Python learning repository! This course is structured from absolute beginner concepts all the way up to advanced software projects and frameworks.

## 📂 Course Modules

- 🟢 **[Module 1: Python Essentials](./module1/README.md)**  
  Variables, Data Types, Conditionals, Loops, and Functions.
- 🟡 **[Module 2: Data Structures & File Handling](./module2/README.md)**  
  Lists, Dictionaries, Tuples, File I/O (`.txt`, `.json`), and Exception Handling.
- 🔵 **[Module 3: OOP & APIs](./module3/README.md)**  
  Object-Oriented Programming (Classes, Inheritance), APIs with `requests`, and `.env` Secrets.
- 🟣 **[Module 4: Frameworks & Real-World Apps](./module4/README.md)**  
  Web Scraping (`BeautifulSoup`), Web APIs (`FastAPI`), Game Dev (`Pygame`), and Data Analysis (`pandas`).

## 🛠️ Getting Started

### 1. Clone the Repository
Open your terminal and clone the repository using Git:

```bash
git clone [https://github.com/RAQuig/Python-ZeroToHero.git](https://github.com/RAQuig/Python-ZeroToHero.git)
cd Python-ZeroToHero

# Create a virtual environment named .venv
python -m venv .venv

# Activate on Linux/macOS:
source .venv/bin/activate

# Activate on Windows (Command Prompt):
.venv\Scripts\activate.bat

# Activate on Windows (PowerShell):
.venv\Scripts\Activate.ps1


pip install -r module3/requirements.txt
pip install -r module4/requirements.txt


# Run a Module 1 lesson file:
python module1/01_variables_and_types.py

# Run a Module 2 lesson file:
python module2/01_lists_and_tuples.py

```
