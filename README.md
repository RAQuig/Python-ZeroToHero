## 🛠️ How to Use This Repo
1. Clone this repository: `git clone <YOUR-REPO-URL>`
2. Open the folder in VS Code.
3. Work through each module's code files sequentially (`01_`, `02_`, etc.).
4. Run the code in your terminal: `python file_name.py`
5. Complete the module project at the end!
